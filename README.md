# Business Name & Slogan Generator (PS64)

## Project Description
This is an AI-powered Business Name and Slogan Generator. It helps startups create unique business names, catchy slogans, and a short business pitch using Generative AI.

## Technologies Used
- Python
- Google Gemini API
- Gradio
- Google Colab

## Features
1. Enter a business idea.
2. Enter the target audience.
3. Select a branding style.
4. Generate 10 creative business names.
5. Generate catchy slogans.
6. Generate a 3-line business pitch.
7. Select and save favourite business names.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Enter your Gemini API key securely.
4. Run all notebook cells.
5. Open the Gradio application link.
